# Python Function Plotting and Root Visualization

## Overview

This project demonstrates how to define mathematical functions, visualize their graphs, and highlight estimated root locations using Python.

It uses NumPy to generate numerical data and Matplotlib to create clear, organized visualizations.

## Features

- Define and plot multiple mathematical functions.
- Visualize function behavior over specified intervals.
- Mark estimated roots on graphs.
- Display root locations using points and vertical lines.
- Create multiple plots in a single figure.
- Use a reusable plotting function to avoid code duplication.

## Technologies

- Python 3
- NumPy
- Matplotlib

## Getting Started

Install the required libraries:

```bash
pip install numpy matplotlib
```

Run the script:

```bash
python main.py
```
